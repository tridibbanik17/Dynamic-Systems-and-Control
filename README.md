# Dynamic Systems and Control

A collection of algorithms, simulations, and models for analyzing and designing control systems.

## 🛠️ Technologies
- MATLAB & Simulink: Used for system modeling, simulation, and control law design.

- Quarc (Quanser Real-Time Control): Enables real-time execution of Simulink models on hardware.

- Control System Toolbox: For frequency domain analysis (Bode, Nyquist) and state-space design.
